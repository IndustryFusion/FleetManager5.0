# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub: open the **Security** tab of this repository and choose
**Report a vulnerability**. Only the maintainers can see the report. We will acknowledge it,
investigate, and agree a fix and a disclosure date with you.

## Supported versions

Only the latest state of the `main` branch is supported. Fixes are not backported.
